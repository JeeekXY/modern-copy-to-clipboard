Modern Copy to Clipboard Demo

Copy Functions

Plain Text Copy

Sample text to copy
await copyToClipboard('This is a test text')

Rich Text Copy

formatted HTML text
await copyToClipboard({ 'text/html': 'formatted HTML text' })

PNG Image Copy

await copyToClipboard({ 'image/png': fetch('https://avatars.githubusercontent.com/u/192025586').then(res => res.blob()) })

Custom MIME Copy

JSON format data
await copyToClipboard({ 'application/json': new Blob([JSON.stringify({ hello: 'world', test: true })], { type: 'application/json' }) })
